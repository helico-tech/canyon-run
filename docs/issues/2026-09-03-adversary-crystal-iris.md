# Adversary: crystal iris that blooms open across the spires core

## Observation

An iris of crystal shards set in the spires' core that blooms open and closed on
the station period: the plane must arrive while the petals are open. Fits the
biome (FEATURE_CRYSTAL prisms) and stays in the plane of the station. Needs a
new shape (petal wedges rotating about the core centre) and a placement rule
that guarantees the open phase leaves the level hull a lane; the audit already
checks reachability, so the period must exceed the approach time.

From the EPIC-10 research (`docs/research/2026-09-03-06-adversaries-design.md`).
