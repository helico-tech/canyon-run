# Show the biome name and an upcoming-gate cue on the HUD

## Observation


## Resolution
The HUD shows score, speed, altitude, horizon and glows but not which biome the player is in or how far the next gate is. A small label near the seed and a distance countdown before a boundary would help players read the difficulty steps.
